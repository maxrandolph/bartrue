Unlock PDF

Remove password protection from a PDF you already have the password for. This does not crack or bypass unknown passwords.

Runs 100% locally
Supports the common standard security handlers: 40-bit and 128-bit RC4, and 128-bit AES. 256-bit AES (PDF 2.0, revision 6) isn't supported yet and will show a clear error instead of a silently broken file.
🔒 Everything happens in-memory in this tab; nothing is uploaded.
