PNG to SVG

Wrap a raster image in an SVG container so it can be dropped anywhere an SVG is expected.

Runs 100% locally
This embeds your original image (as Base64) inside an SVG wrapper with the correct viewBox — it does not trace it into actual vector paths. The image will still look like a photo, not line art, but the file becomes a valid, scalable .svg that any SVG-aware tool can open.
🔒 Everything happens in-memory in this tab; nothing is uploaded.
